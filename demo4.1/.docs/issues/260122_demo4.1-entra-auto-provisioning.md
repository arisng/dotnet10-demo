# Task: Auto-provision and link Entra users to local IdentityUser

## Objective
Create an auto-provisioning/account-linking flow so Entra-authenticated users are matched to local `IdentityUser` records, enabling hybrid identity features and local permission storage.

## Tasks
- Add a provisioning service that creates/links local users on first Entra sign-in.
- Persist external login info (Entra object id / upn) for idempotent linking.
- Ensure provisioning runs during the auth flow without breaking sign-in.
- Seed or map default roles/permissions for newly provisioned users.
- Add a verification step for first-time Entra sign-in user creation.

## Acceptance Criteria
- First-time Entra sign-in creates or links a local user record.
- Subsequent sign-ins reuse the same local user linkage.
- Provisioned users receive expected default roles/permissions.
