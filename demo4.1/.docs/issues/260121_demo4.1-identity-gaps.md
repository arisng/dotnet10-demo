# Task: Close demo4.1 identity feature gaps

## Objective
Ensure demo4.1 inherits demo4’s hybrid identity capabilities by addressing missing multi-identity providers, passkey/local identity support, claims mapping, and Entra-to-local auto-provisioning/account linking.

## Progress Notes
- Local/passkey auth implementation is in place; runtime verification is still pending.
- Hybrid auth uses two endpoint families: `/Account/*` (local Identity) and `/MicrosoftIdentity/Account/*` (MIW/Entra).
- `returnUrl` normalization added to avoid absolute URL issues with MIW sign-in.

## Acceptance Criteria
- [ ] demo4.1 supports multi-identity providers (local/passkey + Entra) or explicitly documents why it does not.
- [ ] Claims mapping exists and is verified for Entra users, or the README states the omission.
- [ ] Auto-provisioning/account linking is implemented and validated, or the README states the omission.
- [ ] Verification steps in [demo4.1/README.md](demo4.1/README.md#L63-L107) reflect the final behavior.
