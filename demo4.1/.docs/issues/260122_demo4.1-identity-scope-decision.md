# Decision: Demo4.1 identity scope (hybrid vs Entra-only)

## Objective
Decide whether demo4.1 must fully inherit demo4's hybrid identity story (local/passkey + Entra + claims bridging), or intentionally document an Entra-only scope for the distributed setup.

## Decision
Demo4.1 must support hybrid identity (local/passkey + Entra). The distributed setup should preserve the demo4 hybrid identity story instead of narrowing scope.

## Notes
- Hybrid identity requires two endpoint families:
  - Local Identity: `/Account/*` (login/register/manage/passkeys).
  - Microsoft Identity Web (Entra): `/MicrosoftIdentity/Account/*` (OIDC sign-in/out/challenge).
