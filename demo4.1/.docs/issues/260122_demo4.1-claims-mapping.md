# Task: Add Entra App Roles to local permission claims mapping

## Objective
Implement `IClaimsTransformation` so Entra App Roles (or group claims) map to local permission claims, preserving demo3/4 authorization behavior in demo4.1.

## Tasks
- Port the claims mapping approach from demo4 into demo4.1's auth pipeline.
- Map Entra App Roles (or configured claim source) to local `permission` claims.
- Ensure the permission claims are available for BFF and backend authorization checks.
- Add tests or a verification step that confirms a mapped permission is enforced.

## Acceptance Criteria
- `IClaimsTransformation` is registered and runs for Entra-authenticated users.
- At least one Entra role maps to one or more `permission` claims.
- Permission-based authorization works for mapped Entra users.
