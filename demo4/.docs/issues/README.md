# Demo4 Issue Notes

Use this folder to track temporary or in-flight maintenance items discovered while working on Demo4. Each file should:

1. Follow the filename pattern `YYMMDD_short-title.md`.
2. Describe the observed symptom, the cause (if known), and the current mitigation.
3. Tag the entry with `#investigate`, `#blocking`, `#resolved`, or other relevant keywords.
4. Link back to the supporting docs (e.g., `guidance/implementation-patterns.md`, `reference/quick-reference.md`, or `support/troubleshooting.md`).

When the issue is resolved, mark it as such and cross-link to the verification steps you used.
