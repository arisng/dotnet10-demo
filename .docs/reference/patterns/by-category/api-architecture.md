# API Architecture Patterns

- [Backend-for-Frontend (BFF)](../catalog/api-bff.md) — Tailored server-side backend for a specific frontend client.
- [Downstream API Pattern](../catalog/api-downstream.md) — Call external APIs with bearer tokens and scope checks.
- [YARP (Reverse Proxy) Pattern](../catalog/api-yarp-reverse-proxy.md) — Reverse proxy routing with token injection in a BFF.
- [Bearer Token Validation](../catalog/api-bearer-token-validation.md) — Validate JWT access tokens for API protection.
