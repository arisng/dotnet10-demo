# Authorization Patterns

- [Role-Based Access Control (RBAC)](../catalog/authz-rbac.md) — Role assignments grant access to features and endpoints.
- [Claims Transformation](../catalog/authz-claims-transformation.md) — Enrich identity claims before authorization checks.
- [Auto-Provisioning](../catalog/authz-auto-provisioning.md) — Create or update local users on first external sign-in.
- [Permission-Based RBAC](../catalog/authz-permission-rbac.md) — Roles map to fine-grained permissions.
- [Authorization Handlers](../catalog/authz-authorization-handlers.md) — Custom handlers evaluate authorization requirements.
- [OAuth Scopes](../catalog/authz-oauth-scopes.md) — Coarse-grained API permissions granted by user consent.
- [Claims Mapping](../catalog/authz-claims-mapping.md) — Map provider claims to local roles and permissions.
