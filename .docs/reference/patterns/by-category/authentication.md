# Authentication Patterns

- [Cookie-Based Authentication (Local Identity)](../catalog/auth-cookie-based.md) — Server-side session management using HTTP cookies.
- [Passkey Authentication (WebAuthn)](../catalog/auth-passkey.md) — Passwordless authentication using the WebAuthn API.
- [OpenID Connect (OIDC) External Provider](../catalog/auth-oidc-external-provider.md) — Redirect-based external authentication with ID tokens.
- [Multi-Identity (Hybrid Providers)](../catalog/auth-multi-identity.md) — Multiple authentication providers with unified authorization.
- [On-Behalf-Of (OBO) Flow](../catalog/auth-obo-flow.md) — Token exchange to call downstream APIs on a user's behalf.
