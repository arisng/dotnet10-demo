# Data & Persistence Patterns

- [Outbox Pattern](../catalog/data-outbox.md) — Persist events in the same transaction as state changes.
- [Inbox Pattern](../catalog/data-inbox.md) — Record processed messages to ensure idempotency.
- [Service Abstraction Pattern](../catalog/data-service-abstraction.md) — Interfaces decouple components from data sources.
